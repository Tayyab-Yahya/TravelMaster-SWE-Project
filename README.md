## 📖 Overview

**TravelMaster** is a Software Engineering semester project focused on applying formal software development lifecycle (SDLC) principles—from requirements engineering and system modeling to modular implementation and testing. The platform provides travelers with an intuitive interface to explore destinations, build custom itineraries, and manage reservations seamlessly.

---

## ✨ Key Features

- **🔐 User Authentication & Profiles:** Secure registration, login, and role-based access (Traveler / Admin).
- **🗺️ Destination Explorer:** Browse curated travel packages, routes, and destination details.
- **📅 Smart Itinerary Builder:** Create, customize, and organize day-by-day travel schedules.
- **🎫 Booking & Reservation Management:** Real-time booking workflow with status tracking and history.
- **💳 Cost Estimation & Billing:** Transparent breakdown of package, transport, and accommodation costs.
- **🛠️ Admin Dashboard:** Manage packages, monitor bookings, and oversee user activity.
